# fse-gatewarden

Greenfield selector-first Fused Semantic Execution core for Gatewarden.

This crate is a side-by-side rewrite track focused on:

- compile-time selector deduplication
- single-pass runtime dispatch
- rule-state bitmap evaluation
- deterministic fail-closed decisions
- early-exit semantics

## Status

Experimental v0.1.0 side-by-side track.
